# Welcome to TamaTUI - Snake!!!

## Description

This is a TUI Snake game coded in python using the Curses library for educational material at Holberton School Australia.

## Requirements and Installation

Please install the requirements listed inside of requirements.txt.
Once requirements have been installed, the game may be run by executing main.py.
